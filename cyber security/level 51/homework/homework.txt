-sL (სამიზნეების სიის ჩვენება) — აჩვენებს იმ IP მისამართების სიას, რომელთა შემოწმებაც იგეგმება, თუმცა რეალურ პორტების სკანირებას არ ატარებს. 
გამოიყენება იმის გასაგებად, თუ რომელი მოწყობილობები შედის მითითებულ დიაპაზონში

-sn (აქტიური მოწყობილობების აღმოჩენა) — ამოწმებს, რომელი მოწყობილობებია ქსელში აქტიური, თუმცა პორტებს არ ამოწმებს. 
მისი საშუალებით შეგვიძლია გავიგოთ, რომელი მოწყობილობები არიან დაკავშირებული ქსელთან

-sT (TCP Connect სკანირება) — ამოწმებს TCP პორტებს სრული TCP კავშირის დამყარებით. თუ კავშირი წარმატებით დამყარდა, პორტი ღიად ითვლება. ეს მეთოდი ჩვეულებრივ მომხმარებლის უფლებებითაც მუშაობს

-sS (SYN სკანირება) — იყენებს TCP SYN პაკეტს პორტის მდგომარეობის შესამოწმებლად. სრული TCP კავშირი არ მყარდება, ამიტომ მას ხშირად ნახევრად ღია სკანირებასაც უწოდებენ

-sU (UDP სკანირება) — ამოწმებს UDP პორტებს. გამოიყენება ისეთი სერვისების აღმოსაჩენად, რომლებიც UDP პროტოკოლს იყენებენ, მაგალითად DNS. UDP სკანირება ხშირად უფრო ნელია, ვიდრე TCP სკანირება

-F (სწრაფი სკანირება) — ამოწმებს 100 ყველაზე გავრცელებულ პორტს, ნაცვლად ყველა 1000 სტანდარტული TCP პორტისა. 
გამოიყენება სწრაფი შემოწმებისთვის, როდესაც ყველა პორტის დეტალურად შემოწმება საჭირო არ არის

-p [range] (პორტების მითითება) — საშუალებას გვაძლევს თავად ავირჩიოთ, რომელი პორტები უნდა შემოწმდეს. შეგვიძლია მივუთითოთ ერთი კონკრეტული პორტი ან პორტების დიაპაზონი

-Pn (ჰოსტის აღმოჩენის გამოტოვება) — Nmap წინასწარ არ ამოწმებს, არის თუ არა მოწყობილობა აქტიური და პირდაპირ იწყებს მის სკანირებას. 
სასარგებლოა მაშინ, როდესაც მოწყობილობა აღმოჩენის მოთხოვნებს არ პასუხობს, მაგრამ რეალურად მუშაობს

-O (ოპერაციული სისტემის აღმოჩენა) — ცდილობს დაადგინოს, რომელ ოპერაციულ სისტემას იყენებს სამიზნე მოწყობილობა, მაგალითად Windows, Linux ან macOS. 
ამისთვის აანალიზებს ქსელურ პასუხებსა და მათ მახასიათებლებს

-sV (სერვისებისა და ვერსიების აღმოჩენა) — ამოწმებს ღია პორტებზე გაშვებულ სერვისებს და ცდილობს დაადგინოს მათი სახელები და ვერსიები. 
მაგალითად, შეიძლება აღმოაჩინოს, რომ 80 პორტზე მუშაობს Apache ვებ სერვერი

-A (გაფართოებული სკანირება) — აერთიანებს რამდენიმე ფუნქციას: ოპერაციული სისტემის აღმოჩენას, სერვისებისა და ვერსიების შემოწმებას, სკრიპტების სკანირებას და traceroute-ს. 
გამოიყენება სამიზნის შესახებ უფრო დეტალური ინფორმაციის მისაღებად


nmap-ი მეხმარება რომ აღმოვაჩინო port-ები და service-ები კონკრეტულ ip-ზე და gobuster-ი მეხმარება რომ აღმოვაჩინო დამალული ბილიკები/ფაილები

1. port-ი არის "ოთახი" სადაც გამოყოფილია გარკვეული რესურსი და მუშაობს გარკვეული service-ი
2. nmap-ი მაწვდის თუ რა service-ებია გაშვებულ და რომელ port-ებზე
3. gobuster-ი მეხმარება რომ აღმოვაჩინო დამალული ბილიკები/ფაილები
4. 200 OK - მოთხოვნა წარმატებით შესრულდა
   301 Moved Permanently - გვერდი მუდმივად სხვა მისამართზე გადავიდა
   403 Forbidden - წვდომა აკრძალულია
   404 Not Found - მოთხოვნილი გვერდი ვერ მოიძებნა
5. ღია პორტი ავტომატურად დაუცველობას არ ნიშნავს, რადგან ის შეიძლება საჭირო სერვისისთვის იყოს გახსნილი და სათანადოდ დაცული იყოს. დაუცველობა დამოკიდებულია სერვისის კონფიგურაციასა და უსაფრთხოებაზე
6. მნიშვნელოვანია, რადგან არასაჭირო ან დაუცველმა რესურსებმა შეიძლება თავდამსხმელებს სისტემაზე წვდომის და ინფორმაციის მოპარვის შესაძლებლობა მისცეს
7. არასაჭირო პორტებისა და სერვისების დახურვა
   ძლიერი პაროლების გამოყენება
   სისტემისა და პროგრამების რეგულარული განახლება
   Firewall-ის გამოყენება
   მომხმარებლებისთვის შესაბამისი უფლებების მინიჭება
   სერვერის რეგულარული მონიტორინგი
