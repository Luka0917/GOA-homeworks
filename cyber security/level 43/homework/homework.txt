TLS (Transport Layer Security)
TLS არის უსაფრთხოების პროტოკოლი, რომელიც ინტერნეტში მოწყობილობებს შორის გადაცემულ ინფორმაციას შიფრავს
მისი მთავარი ფუნქციებია:
- დაშიფვრა: იცავს ინფორმაციას უცხო პირებისგან
- ავთენტიფიკაცია: ამოწმებს სერვერის ნამდვილობას ციფრული სერტიფიკატით
- მთლიანობის დაცვა: ამოწმებს, ხომ არ შეიცვალა ინფორმაცია გადაცემის დროს
მაგალითად, როდესაც ვებსაიტზე პაროლს წერ, TLS იცავს მის გადაცემას

HTTPS (HTTP Secure)
HTTPS არის HTTP პროტოკოლის დაცული ვერსია, რომელიც TLS-ს იყენებს ბრაუზერსა და ვებსაიტს შორის კავშირის დასაშიფრად
ის უზრუნველყოფს:
- გადაცემული ინფორმაციის დაცვას
- ვებსაიტის სერტიფიკატის შემოწმებას
- ინფორმაციის შეცვლისგან დაცვას
მაგალითად, ონლაინ მაღაზიაში გადახდისას HTTPS იცავს შენსა და ვებსაიტს შორის კომუნიკაციას
პორტი: 443

SMTPS (SMTP Secure)
SMTP არის პროტოკოლი, რომელიც გამოიყენება ელფოსტის გასაგზავნად, ხოლო SMTPS უზრუნველყოფს ამ კომუნიკაციის დაცვას TLS დაშიფვრის საშუალებით
ის იცავს ელფოსტის კლიენტსა და სერვერს შორის გადაცემულ ინფორმაციას, მათ შორის ავტორიზაციის მონაცემებს
მაგალითად, როდესაც Gmail-ის მსგავსი სერვისიდან წერილს აგზავნი, უსაფრთხო კავშირი იცავს მონაცემებს გადაცემისას
პორტი: 465. ასევე გამოიყენება 587 STARTTLS-ით

POP3S (Post Office Protocol Secure)
POP3 არის პროტოკოლი, რომლის საშუალებითაც ელფოსტის პროგრამა სერვერიდან წერილებს იღებს. POP3S კი ამ პროცესს TLS დაშიფვრით იცავს
მისი მთავარი დანიშნულებაა:
- წერილების სერვერიდან ჩამოტვირთვა
- წერილების ლოკალურად, მოწყობილობაზე შენახვა
- ელფოსტაზე უსაფრთხო წვდომა
მაგალითად, შეგიძლია წერილები ჩამოტვირთო კომპიუტერში და ინტერნეტის გარეშეც წაიკითხო
პორტი: 995

IMAPS (Internet Message Access Protocol Secure)
IMAP გამოიყენება ელფოსტის მისაღებად და სერვერზე სამართავად. IMAPS კი ამ კავშირს TLS დაშიფვრით იცავს
POP3-ისგან განსხვავებით, IMAP ძირითადად წერილებს სერვერზე ტოვებს და სხვადასხვა მოწყობილობას შორის სინქრონიზაციას უზრუნველყოფს
მაგალითად:
- ტელეფონში კითხულობ წერილს
- კომპიუტერში ხსნი ელფოსტას
- იგივე წერილი უკვე წაკითხულად გხვდება
პორტი: 993

SSH (Secure Shell)
SSH არის პროტოკოლი, რომელიც საშუალებას გვაძლევს უსაფრთხოდ დავუკავშირდეთ სხვა კომპიუტერს ქსელის საშუალებით
მისი გამოყენებით შეგვიძლია:
- დისტანციურად შევიდეთ კომპიუტერში
- შევასრულოთ ტერმინალის ბრძანებები
- ვმართოთ Linux სერვერები
- უსაფრთხოდ გადავცეთ მონაცემები
მაგალითად, სახლიდან გასვლისას შეგიძლია ლეპტოპით დაუკავშირდე შენს სახლის Linux სერვერს და მართო ის ტერმინალიდან
პორტი: 22

7. SFTP (SSH File Transfer Protocol)
SFTP არის პროტოკოლი, რომელიც გამოიყენება ფაილების უსაფრთხოდ გადასატანად კომპიუტერებს შორის. ის SSH კავშირს იყენებს, ამიტომ გადაცემული მონაცემები დაშიფრულია
მისი საშუალებით შეგვიძლია:
- ფაილების ატვირთვა
- ფაილების ჩამოტვირთვა
- ფაილების წაშლა და გადარქმევა
- დისტანციური საქაღალდეების ნახვა
მაგალითად, შეგიძლია შენი ვებსაიტის ფაილები ლეპტოპიდან Linux სერვერზე ატვირთო
პორტი: 22

FTPS (FTP Secure)
FTPS არის FTP პროტოკოლის დაცული ვერსია, რომელიც TLS დაშიფვრას იყენებს
მისი დანიშნულებაა ფაილების უსაფრთხოდ გადატანა კომპიუტერებსა და სერვერებს შორის
არსებობს ორი ტიპი:
- Explicit FTPS: კავშირი იწყება ჩვეულებრივი FTP-ით და შემდეგ გადადის დაშიფრულ რეჟიმში
- Implicit FTPS: კავშირი თავიდანვე დაშიფრულია
მაგალითად, კომპანიას შეუძლია FTPS გამოიყენოს ფაილების უსაფრთხოდ გასაცვლელად სხვა კომპანიასთან
პორტები: 21 (Explicit) და 990 (Implicit)

VPN (Virtual Private Network)
VPN არის ტექნოლოგია, რომელიც ქმნის დაშიფრულ კავშირს შენს მოწყობილობასა და VPN სერვერს ან კერძო ქსელს შორის. ამ კავშირს ხშირად „ტუნელს“ უწოდებენ
VPN-ის ძირითადი დანიშნულებებია:
- ინტერნეტ ტრაფიკის დაცვა
- საჯარო Wi-Fi ქსელებში უსაფრთხოების გაუმჯობესება
- დისტანციურად კერძო ქსელთან დაკავშირება
- ვებსაიტებისთვის შენი საწყისი საჯარო IP მისამართის დამალვა VPN სერვერის მისამართით
