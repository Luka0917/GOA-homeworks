XSS არის შეტევა, რომლის დროსაც თავდამსხმელი ვებგვერდში მავნე JS-ის კოდს ათავსებს, რათა მოიპაროს მომხმარებლის მონაცემები ან გამოიყენოს მისი სესია

თავდამსხმელი მავნე JavaScript კოდს ათავსებს ვებგვერდის შესავსებ ველში. თუ საიტი კოდს სწორად არ ფილტრავს, ბრაუზერმა შეიძლება ის შეასრულოს და მომხმარებლის მონაცემები საფრთხის ქვეშ დააყენოს

Stored XSS: თავდამსხმელი კომენტარში ათავსებს მავნე კოდს, რომელიც მონაცემთა ბაზაში ინახება და სხვა მომხმარებლის გახსნისას სრულდება
Reflected XSS: თავდამსხმელი მომხმარებელს სპეციალურ ბმულს უგზავნის, რომლის გახსნისას მავნე კოდი გვერდის პასუხში ბრუნდება და სრულდება
DOM-Based XSS: საიტის JavaScript URL-იდან მიღებულ მონაცემს სახიფათოდ ამუშავებს, რის შედეგადაც ბრაუზერი მავნე კოდს ასრულებს

XSS შეტევამ შეიძლება გამოიწვიოს მომხმარებლის პირადი მონაცემების მოპარვა, ანგარიშზე უნებართვო მოქმედებების შესრულება, 
ყალბი შესვლის ფორმებით პაროლების მოპარვა და ვებგვერდის შიგთავსის შეცვლა ზიანის მასშტაბი დამოკიდებულია საიტის უსაფრთხოების სისუსტეებზე და დაცვის მექანიზმებზე

ოპერაციული სისტემა არის პროგრამა, რომელიც მართავს კომპიუტერის რესურსებს და უზრუნველყოფს სხვა პროგრამების მუშაობას

Kernel (ბირთვი) არის ოპერაციული სისტემის ძირითადი ნაწილი, რომელიც მართავს კომპიუტერის აპარატურულ რესურსებს და პროგრამებს შორის კავშირს

მისი ძირითადი ფუნქციებია:
1. პროცესების მართვა - განსაზღვრავს, რომელი პროგრამა და როდის იმუშავებს
2. მეხსიერების მართვა - ანაწილებს RAM-ს პროგრამებს შორის
3. მოწყობილობების მართვა - უზრუნველყოფს პროცესორის, კლავიატურის, დისკისა და სხვა მოწყობილობების მუშაობას
4. რესურსების განაწილება - აკონტროლებს, როგორ იყენებენ პროგრამები კომპიუტერის რესურსებს

Kernel Space არის მეხსიერების ნაწილი, სადაც Kernel მუშაობს და აქვს კომპიუტერის აპარატურულ რესურსებზე მაღალი დონის წვდომა
მისი მთავარი დანიშნულებაა ოპერაციული სისტემის ძირითადი ფუნქციების შესრულება, მაგალითად, RAM-ის, პროცესებისა და მოწყობილობების მართვა

User Space არის მეხსიერების ნაწილი, სადაც ჩვეულებრივი პროგრამები მუშაობს ისე, რომ პირდაპირ არ აქვთ Kernel-ის მსგავსად სრული წვდომა კომპიუტერის რესურსებზე
თუ პროგრამას სჭირდება RAM-თან ან მოწყობილობასთან დაკავშირებული გარკვეული მოქმედების შესრულება, ის Kernel-ს მიმართავს

Kernel Space-სა და User Space-ს შორის მთავარი განსხვავება არის წვდომის დონე
Kernel Space-ს აქვს მაღალი დონის წვდომა
User Space-ს აქვს შეზღუდილი წვდომა

System Calls (სისტემური გამოძახებები) არის მექანიზმი, რომლის საშუალებითაც User Space-ში გაშვებული პროგრამები Kernel-ს სთხოვენ კონკრეტული მოქმედებების შესრულებას
მაგალითი: პროგრამას სჭირდება ფაილის წაკითხვა, მაგრამ ამისთვის Kernel-ის დახმარება სჭირდება. ის აკეთებს System Call-ს, Kernel კითხულობს ფაილს და შედეგს პროგრამას უბრუნებს

Process (პროცესი) არის გაშვებული პროგრამა, რომელსაც აქვს საკუთარი მეხსიერება და სისტემური რესურსები
Thread (ნაკადი) არის პროცესის შიგნით შესრულების ერთეული, რომელიც კონკრეტულ დავალებას ასრულებს. ერთ პროცესს შეიძლება რამდენიმე Thread ჰქონდეს

Kernel-ის იზოლაცია მნიშვნელოვანია, რადგან ის იცავს ოპერაციული სისტემის ბირთვს ჩვეულებრივი პროგრამებისგან
მისი მნიშვნელობა:
1. უსაფრთხოება — მავნე პროგრამას არ შეუძლია პირდაპირ და შეუზღუდავად მართოს სისტემის რესურსები
2. სტაბილურობა — ერთი პროგრამის შეცდომა ნაკლებად იწვევს მთელი სისტემის დაზიანებას
3. წვდომის კონტროლი — პროგრამებს მხოლოდ იმ რესურსებზე აქვთ წვდომა, რისი უფლებაც აქვთ
