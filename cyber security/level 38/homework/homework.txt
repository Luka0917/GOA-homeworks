- DHCP (Dynamic Host Configuration Protocol)
DHCP ავტომატურად ანიჭებს მოწყობილობებს IP მისამართებს, როდესაც ისინი ქსელს უკავშირდებიან. 
ის ასევე აწვდის ქსელის სხვა პარამეტრებს, მაგალითად, ძირითად კარიბჭეს (Default Gateway) და DNS სერვერს. 
DHCP-ის გარეშე ამ პარამეტრების ხელით მითითება შეიძლება დაგჭირდეს. მაგალითად, როუტერს შეუძლია ლეპტოპს IP მისამართი ავტომატურად მიანიჭოს

- ARP (Address Resolution Protocol)
ARP ლოკალურ ქსელში IPv4 მისამართის შესაბამის MAC მისამართს პოულობს. 
როდესაც მოწყობილობას მონაცემების გაგზავნა სურს, მაგრამ მიმღების MAC მისამართი არ იცის, ის აგზავნის ARP Request-ს. 
მოწყობილობა, რომელსაც შესაბამისი IP მისამართი აქვს, პასუხობს თავისი MAC მისამართით

- NAT (Network Address Translation)
NAT როუტერის გავლით მონაცემების გადაცემისას IP მისამართების ინფორმაციას ცვლის. 
ის ხშირად საშუალებას აძლევს სახლის ქსელში არსებულ რამდენიმე მოწყობილობას, ინტერნეტთან წვდომისთვის ერთი საჯარო IPv4 მისამართი გამოიყენონ.
მაგალითად, ტელეფონსა და ლეპტოპს შეიძლება სხვადასხვა კერძო IP მისამართი ჰქონდეთ, მაგრამ ინტერნეტში ერთი საჯარო IP მისამართით გადიოდნენ

- ICMP (Internet Control Message Protocol)
ICMP გამოიყენება ქსელური შეცდომების შესახებ შეტყობინებების გასაგზავნად და კავშირის შესამოწმებლად. 
ping ბრძანება ხშირად ICMP-ს იყენებს იმის შესამოწმებლად, ხელმისაწვდომია თუ არა სხვა მოწყობილობა და რამდენი დრო სჭირდება პასუხის მიღებას. 
ქსელურ მოწყობილობებს ასევე შეუძლიათ ICMP-ით მიუთითონ პრობლემებზე, მაგალითად, მიუწვდომელ დანიშნულების მისამართზე

- Routing (მარშრუტიზაცია)
მარშრუტიზაცია არის მონაცემთა პაკეტებისთვის ქსელებს შორის გზის შერჩევის პროცესი. 
როუტერები მარშრუტიზაციის ცხრილებს იყენებენ იმის გადასაწყვეტად, თუ სად უნდა გადააგზავნონ პაკეტები. როდესაც ვებსაიტს ხსნი, 
როუტერები პაკეტებს სხვადასხვა ქსელის გავლით დანიშნულების ადგილამდე აგზავნიან. 
მარშრუტიზაცია შეიძლება ხდებოდეს ხელით მითითებული მარშრუტებით ან დინამიკური მარშრუტიზაციის პროტოკოლებით
