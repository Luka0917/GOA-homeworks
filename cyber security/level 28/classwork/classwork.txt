1. Client & Server
ანალოგია: რესტორანი
Client არის მომხმარებელი, რომელიც საჭმელს უკვეთავს
Server არის სამზარეულო, რომელიც შეკვეთას ამზადებს
მაგალითად, ბრაუზერი არის Client, ხოლო ვებსაიტის კომპიუტერი — Server

2. Request & Response
ანალოგია: რესტორანში საჭმლის შეკვეთა
Request არის შეკვეთა, რომელსაც მომხმარებელი აკეთებს
Response არის მზა საჭმელი, რომელსაც მომხმარებელი იღებს
ინტერნეტში Client აგზავნის მოთხოვნას, ხოლო Server პასუხს უბრუნებს

3. Protocol
ანალოგია: საერთო ენა და წესები
თუ მომხმარებელი და მიმტანი შეკვეთის წესებს ვერ გაიგებენ
შეკვეთის შესრულება გართულდება
Protocol არის წესების ნაკრები, რომლის მიხედვითაც
მოწყობილობები ერთმანეთს ინფორმაციას უცვლიან
მაგალითად: HTTP, HTTPS

4. Port
ანალოგია: შენობაში სხვადასხვა ოთახი, სადაც სხვადასხვა საქმე კეთდება
IP მისამართი მიუთითებს კომპიუტერზე
ხოლო Port განსაზღვრავს, რომელ პროგრამას ან სერვისს
უნდა გადაეცეს ინფორმაცია
მაგალითად: პორტი 80 ხშირად გამოიყენება HTTP-სთვის
ხოლო 443 — HTTPS-სთვის

5. DNS (Domain Name System)
ანალოგია: ტელეფონის კონტაქტები
კონტაქტებში ადამიანის სახელს ვეძებთ და მის ნომერს ვიღებთ
DNS-ის საშუალებით დომენის სახელს, მაგალითად google.com-ს
შესაბამის IP მისამართს ვუკავშირებთ
ასე აღარ გვჭირდება ვებსაიტის IP მისამართის დამახსოვრება
