Cloud Hosting არის ჰოსტინგის ტიპი, რომლის დროსაც ვებსაიტები და აპლიკაციები მუშაობს ინტერნეტთან დაკავშირებულ რამდენიმე სერვერზე. 
ის იყენებს ღრუბლოვან რესურსებს, რომელთა მართვა და გაზრდა საჭიროების მიხედვით შესაძლებელია

როგორ მუშაობს:
მომხმარებლის მოთხოვნები იგზავნება ღრუბლოვან სერვერებზე, რომლებიც ამუშავებენ მოთხოვნებს და აბრუნებენ შედეგს

პლიუსები:
- მარტივად იზრდება რესურსების რაოდენობა
- მაღალი საიმედოობა
- ხშირად ვიხდით მხოლოდ გამოყენებული რესურსებისთვის

მინუსები:
- საჭიროა ინტერნეტთან კავშირი
- ხარჯები შეიძლება გაიზარდოს
- დამოკიდებულია ჰოსტინგის პროვაიდერზე

რისთვის გამოიყენება: ვებსაიტების, ონლაინ მაღაზიების, აპლიკაციების, მონაცემთა ბაზებისა და ფაილების შესანახად

მაგალითები:
- Amazon Web Services (AWS)
- Google Cloud
- Microsoft Azure
- DigitalOcean

Cloud Hosting არის მოქნილი და მასშტაბირებადი ჰოსტინგი, რომელიც საშუალებას გვაძლევს, 
ინტერნეტით ხელმისაწვდომი სერვისები ღრუბლოვანი სერვერების გამოყენებით გავუშვათ


DevOps არის მიდგომა, რომელიც აერთიანებს პროგრამული უზრუნველყოფის დეველოპმენტს (Development) და ოპერაციებს (Operations). 
მისი მიზანია პროგრამების უფრო სწრაფად, ხარისხიანად და საიმედოდ შექმნა, ტესტირება და მომხმარებლებისთვის მიწოდება

როგორ ეხმარება პროგრამული უზრუნველყოფის შექმნასა და მართვას:
DevOps ავტომატიზებს პროგრამის შექმნის, ტესტირების, განახლებისა და სერვერზე განთავსების პროცესებს.
ეს ამცირებს შეცდომებს, ზოგავს დროს და ამარტივებს პროგრამის მართვას

DevOps-ის ძირითადი ინსტრუმენტები:
- Git და GitHub - კოდის ვერსიების მართვა
- Docker - პროგრამების კონტეინერებში გაშვება
- Jenkins და GitHub Actions - ტესტირებისა და განახლებების ავტომატიზაცია
- Kubernetes - კონტეინერების მართვა
- Terraform - ინფრასტრუქტურის ავტომატიზებული შექმნა
- Prometheus და Grafana - სისტემის მონიტორინგი

DevOps ეხმარება გუნდებს პროგრამების უფრო სწრაფად შექმნაში, ტესტირებაში, განახლებასა და საიმედოდ მუშაობის უზრუნველყოფაში


1. რა არის კონტეინერი:
კონტეინერი (Container) არის იზოლირებული გარემო, რომელშიც პროგრამა და მისი მუშაობისთვის საჭირო ფაილები, 
ბიბლიოთეკები და დამოკიდებულებები ერთად არის მოთავსებული. ეს საშუალებას გვაძლევს, პროგრამა სხვადასხვა კომპიუტერზე თანმიმდევრულად გავუშვათ

2. როგორ მუშაობს კონტეინერი
კონტეინერი იყენებს მასპინძელი ოპერაციული სისტემის (Host OS) ბირთვს (Kernel), თუმცა პროგრამის პროცესები და რესურსები იზოლირებულია სხვა პროგრამებისგან. 
კონტეინერის შიგნით მოთავსებულია პროგრამა და მისი საჭირო ფაილები
მაგალითად, თუ შევქმნით კონტეინერს Python-ის პროგრამისთვის, მასში შეგვიძლია მოვათავსოთ Python-ის შესაბამისი ვერსია, საჭირო ბიბლიოთეკები და ჩვენი კოდი. 
შედეგად, პროგრამა უფრო მარტივად გაეშვება სხვადასხვა გარემოში

3. რით განსხვავდება კონტეინერი ვირტუალური მანქანისგან:
ვირტუალური მანქანა (Virtual Machine) ვირტუალურ აპარატურას და საკუთარ ოპერაციულ სისტემას იყენებს, 
ხოლო კონტეინერი მასპინძელი სისტემის ბირთვს იზიარებს

- ვირტუალური მანქანა, როგორც წესი, მეტ მეხსიერებასა და დისკის სივრცეს მოითხოვს
- კონტეინერები, როგორც წესი, უფრო მსუბუქია და სწრაფად ეშვება
- ვირტუალურ მანქანაში შესაძლებელია დამოუკიდებელი ოპერაციული სისტემის გაშვება
- კონტეინერები იზოლირებულია, თუმცა ყველა კონტეინერი დამოუკიდებელ ბირთვს არ იყენებს

4. რა არის Docker:
Docker არის პლატფორმა, რომელიც კონტეინერების შექმნას, გაშვებას და მართვას ამარტივებს
Docker-ის ძირითადი კომპონენტებია:
- Image - შაბლონი, რომელიც შეიცავს პროგრამის გასაშვებად საჭირო ფაილებსა და პარამეტრებს
- Container - გაშვებული, იზოლირებული გარემო, რომელიც Image-ის საფუძველზე იქმნება
- Dockerfile — ინსტრუქციების ფაილი, რომელიც აღწერს, როგორ შეიქმნას Image
- Docker Hub — სერვისი, საიდანაც შესაძლებელია მზა Image-ების ჩამოტვირთვა და საკუთარი Image-ების გამოქვეყნება

5. რა უპირატესობები აქვს კონტეინერებს:
1. პორტაბელურობა: პროგრამა სხვადასხვა გარემოში უფრო მარტივად მუშაობს
2. სისწრაფე: კონტეინერები სწრაფად ეშვება, რადგან ცალკე ოპერაციული სისტემის ჩატვირთვა არ სჭირდება
3. რესურსების ეფექტური გამოყენება: ჩვეულებრივ, ნაკლებ RAM-სა და დისკის სივრცეს მოიხმარს, ვიდრე სრულფასოვანი ვირტუალური მანქანა
4. იზოლაცია: პროგრამებისა და მათი დამოკიდებულებების განცალკევებას უზრუნველყოფს
5. მასშტაბირება: შესაძლებელია კონტეინერების რაოდენობის გაზრდა ან შემცირება მოთხოვნის მიხედვით
6. გამარტივებული განახლება: პროგრამის ახალი ვერსიის შექმნა და გაშვება მარტივდება

6. სად გამოიყენება კონტეინერები:
კონტეინერები გამოიყენება ვებსაიტების, API-ების, მონაცემთა დამუშავების სისტემებისა და მიკროსერვისების გასაშვებად. 
მაგალითად, დეველოპერს შეუძლია React-ის ვებსაიტისა და Node.js-ის სერვერის ცალკეულ კონტეინერებში გაშვება

კონტეინერები პროგრამების იზოლირებულ გარემოში გაშვების ეფექტური საშუალებაა. 
Docker კი ამ პროცესის მართვას ამარტივებს. 
კონტეინერები განსაკუთრებით სასარგებლოა პროგრამული უზრუნველყოფის შექმნის, ტესტირების, განახლებისა და სერვერებზე განთავსების დროს
