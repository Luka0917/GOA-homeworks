- DNS (Domain Name System)
DNS დომენის სახელს IP მისამართად გარდაქმნის. 
მაგალითად, როცა წერ google.com, DNS ეხმარება მოწყობილობას შესაბამისი სერვერის IP მისამართის პოვნაში. 
მას ხშირად ინტერნეტის სატელეფონო ცნობარს უწოდებენ

- WHOIS
WHOIS გამოიყენება დომენის ან IP მისამართის შესახებ საჯარო სარეგისტრაციო ინფორმაციის მოსაძიებლად. 
დომენის შემთხვევაში შეიძლება აჩვენოს რეგისტრატორი, რეგისტრაციისა და ვადის გასვლის თარიღები. 
ზოგიერთი ინფორმაცია კონფიდენციალურობის გამო დამალულია

- HTTP / HTTPS
HTTP არის პროტოკოლი, რომლითაც ბრაუზერი და ვებ-სერვერი ერთმანეთს ინფორმაციას უცვლიან. 
HTTPS არის HTTP დაშიფრული კავშირით, რომელიც TLS-ს იყენებს მონაცემების დასაცავად და სერვერის იდენტობის შესამოწმებლად

- FTP (File Transfer Protocol)
FTP გამოიყენება ქსელში ფაილების გადასატანად კლიენტსა და სერვერს შორის. 
ის ფაილების ატვირთვისა და ჩამოტვირთვის საშუალებას იძლევა. 
ჩვეულებრივი FTP მონაცემებს არ შიფრავს, ამიტომ უსაფრთხო გადაცემისთვის ხშირად SFTP-ს ან FTPS-ს იყენებენ

- SMTP (Simple Mail Transfer Protocol)
SMTP გამოიყენება ელფოსტის გასაგზავნად. ის ფოსტის პროგრამიდან წერილს ფოსტის სერვერზე აგზავნის, 
ხოლო სერვერებს შორის წერილის გადაცემაშიც მონაწილეობს

- POP3 (Post Office Protocol 3)
POP3 გამოიყენება ელფოსტის სერვერიდან წერილების ჩამოსატვირთად. 
მისი ჩვეულებრივი გამოყენებისას წერილები შეიძლება მოწყობილობაზე შეინახოს, 
თუმცა სერვერზე დატოვებაც შესაძლებელია შესაბამისი პარამეტრით

- IMAP (Internet Message Access Protocol)
IMAP საშუალებას გაძლევს, წერილები პირდაპირ სერვერზე მართო და რამდენიმე მოწყობილობაზე სინქრონიზებული გქონდეს. 
მაგალითად, ტელეფონზე წაკითხული წერილი კომპიუტერზეც წაკითხულად გამოჩნდება
